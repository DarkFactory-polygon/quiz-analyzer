## Цели

### G-01: Понятно, какие темы разобрать со студентами
По результатам квиза видно, какие вопросы студенты не усвоили, чтобы вернуться к этим темам на занятии.

## Функции

### FR-01: Читает результаты квиза из CSV
**Цели:** G-01
**Критерии приёмки:**
- Команда `quiz-analyzer results.csv` читает файл UTF-8 с разделителем-запятой и заголовком student,question,answer,correct, где correct — 1 или 0, и завершается с кодом 0
- Если в строке correct не 1 и не 0 или не хватает полей, в stderr выводится сообщение с номером строки, код выхода ненулевой, отчёт в stdout не печатается
**Слова владельца:** читает результаты квиза из CSV (студент, вопрос, ответ, правильно/нет)

### FR-02: Печатает долю верных ответов по каждому вопросу
**Цели:** G-01
**Критерии приёмки:**
- Для вопроса Q1 с 8 верными ответами из 10 печатается строка с Q1, 80.0% и (8/10)
- Вопросы в таблице идут в порядке первого появления в CSV
**Слова владельца:** печатает долю верных ответов по каждому вопросу

### FR-03: Печатает список самых трудных вопросов
**Цели:** G-01
**Критерии приёмки:**
- При долях Q1 80%, Q2 30%, Q3 45% в списке трудных ровно Q2, затем Q3 — от худшего
- Вопрос с долей ровно 50% при пороге по умолчанию в список не попадает
- С `--threshold 40` при тех же долях в списке трудных только Q2
**Слова владельца:** список самых трудных вопросов
